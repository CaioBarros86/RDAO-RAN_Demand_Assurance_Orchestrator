# RDAO — resumo

Repositório **architecture-first** para orquestrar o ciclo entre detecção de
ofensor RAN, priorização, encaminhamento, SLA, acompanhamento e verificação de
encerramento.

Neste estágio há especificação, contratos e exemplos sintéticos; não há alegação
de MVP executável ou integração produtiva já implementada.
