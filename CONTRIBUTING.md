# Contributing

Contributions are welcome through a focused issue and pull request.

1. Use synthetic or fully anonymized data.
2. Create a branch from the default branch.
3. Add or update tests for behavior changes.
4. Run the test and lint commands documented in the README.
5. Keep implemented behavior separate from roadmap proposals.
6. Never commit credentials, personal data, proprietary documents, local
   paths, generated caches or production network identifiers.

By contributing, you agree that your contribution is licensed under the MIT
License.
