# Roadmap

## Milestone 1 — local executable model

- Pydantic entity models.
- Explicit transition validator.
- SQLite event and state persistence.
- CLI for ingest, route, verify and inspect.
- Synthetic fixtures and transition tests.

## Milestone 2 — operational assurance

- Idempotent event ingestion.
- Incremental ticket snapshot comparison.
- Persistent-offender closure check.
- SLA escalation and recurrence scoring.
- Immutable audit events.

## Milestone 3 — replaceable adapters

- Generic mail and message adapters.
- Generic ticket-system adapter.
- Dashboard/read-model API.
- Retry, dead-letter and observability contracts.
