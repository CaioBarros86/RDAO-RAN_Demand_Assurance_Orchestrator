# Security policy

## Scope

This repository is a portfolio and research project. It must be used with
synthetic, anonymized or explicitly authorized data only.

## Reporting a vulnerability

Open a private security advisory in the repository. Do not include credentials,
personal data, production identifiers or proprietary network extracts in a
public issue.

## Operational safety

- The software is not authorized to execute changes in a live network.
- Review generated recommendations and commands before any external use.
- Keep secrets outside source control and inject them through environment
  variables or an approved secret manager.
- Treat sample identifiers and coordinates as synthetic.

Supported versions are the latest release and the default branch.
