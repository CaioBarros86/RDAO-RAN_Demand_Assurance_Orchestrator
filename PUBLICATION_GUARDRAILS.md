# Publication guardrails

This public edition was prepared under the following constraints:

- only synthetic or anonymized examples;
- no employer data, private tenant URLs or internal documents;
- no credentials, personal paths, Office author metadata or compiled bytecode;
- no claim that roadmap items are implemented;
- no autonomous execution against a live network;
- historical releases require the same security review as the default branch.

Before every release, scan the final archive—not only the working tree—for
secrets, personal data, proprietary references and generated artifacts.
